# Development Rules

## General
- Always use TypeScript
- Follow modular and scalable architecture
- Avoid unnecessary complexity

## File Structure
- Use App Router (Next.js)
- Keep components reusable
- Separate logic from UI

## Coding Style
- Use clear and consistent naming
- Avoid hardcoded values
- Use environment variables where needed

## Firebase
- Use Firebase for authentication and database
- Do not expose sensitive keys

## AI Instructions
- Generate only what is requested in each task
- Do not modify unrelated files
- Ensure code is functional and error-free
