# Crypto Portfolio App

## Overview
This project is a web application to track cryptocurrency portfolio performance in real-time.

## Core Features
- User authentication (Firebase Auth)
- Portfolio tracking
- Transaction history
- Real-time price updates
- Dashboard analytics

## Tech Stack
- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Firebase (Auth + Firestore)
- Ethers.js (blockchain interaction)
- Recharts (data visualization)

## Goal
Build a clean, scalable, and production-ready crypto portfolio tracker using AI-assisted development (Kiro + Claude).
